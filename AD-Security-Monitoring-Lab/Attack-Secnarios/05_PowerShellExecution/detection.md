# PowerShell Execution — Detection

## Overview

Detects malicious PowerShell use via two complementary controls. Script Block Logging (4104) captures the content of every script block executed, including the decoded form of obfuscated commands. Sysmon Event 1 captures process creation, showing which binaries are spawned by powershell.exe and with what command line.

## MITRE ATT&CK (TTPs)

| Tactic          | Technique                                            | ID        |
| --------------- | ---------------------------------------------------- | --------- |
| Execution       | Command and Scripting Interpreter: PowerShell        | T1059.001 |
| Defense Evasion | Obfuscated Files or Information                      | T1027     |
| Defense Evasion | Obfuscated Files or Information: Command Obfuscation | T1027.010 |

## Event IDs

| Event ID | Channel                                  | Captures                               |
| -------- | ---------------------------------------- | -------------------------------------- |
| 4104     | Microsoft-Windows-PowerShell/Operational | Script block content (decoded)         |
| 1        | Microsoft-Windows-Sysmon/Operational     | Process create (image, parent, hashes) |

## Detection Queries

### 4104 (Script Block Logging)

```spl
index=Powershell_Op EventCode=4104
| table _time, ComputerName, User, Message
| sort -_time
```

### 4104 hunt for known malicious patterns

```spl
index=Powershell_Op EventCode=4104
  ("DownloadString" OR "FromBase64String" OR "IEX" OR "Invoke-Expression" OR "EncodedCommand")
| table _time, ComputerName, User, Message
| sort -_time
```

### Sysmon Event 1 (PowerShell child processes)

```spl
index=* sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 ParentImage="*powershell.exe*"
| table _time, ComputerName, User, Image, CommandLine, ParentImage
| sort -_time
```

## Key Indicators (IOCs)

- 4104 events containing `IEX`, `Invoke-Expression`, `DownloadString`, `FromBase64String`, or other in memory execution primitives.
- 4104 events generated by an account that should not be running PowerShell on the host (e.g. an end user account on a server, or a service account doing scripting).
- Sysmon Event 1 with `ParentImage = powershell.exe` spawning unusual children (whoami, net.exe, reg.exe, certutil, bitsadmin).
- Long encoded command lines passed via `-EncodedCommand`.
- PowerShell connecting outbound to unfamiliar IPs (Sysmon Event 3 network connection, when available).

## Notes

- 4104 is OFF by default and must be enabled via GPO (Windows Components > Windows PowerShell > Turn on PowerShell Script Block Logging).
- The PowerShell Operational channel is not collected by Splunk Universal Forwarder by default. It needs an explicit `inputs.conf` stanza and a target index, plus a forwarder restart.
- Without the Splunk Windows TA, fields like ScriptBlockText do not parse cleanly. Raw text search against the `Message` field works as a fallback.
- The lab used `index=Powershell_Op` for these events. In production, prefer routing PowerShell logs into the same Windows index as other event channels for easier correlation, unless retention or access requirements differ.
- 4104 generates a lot of events (many internal Windows modules log script blocks). Pattern filtering and account scoping are essential to keep the signal useful.
